# Property Value Enhancer

A React application to enhance the value of Indian middle-class residential properties through recommendations and tools.

## Features

- **Admin Panel**: Curate and update property improvement recommendations, manage property listings.
- **User Dashboard**: View property enhancement ideas, submit property details for personalized recommendations.

## Getting Started

1. Install dependencies:
   ```
   npm install
   ```

2. Start the development server:
   ```
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

To build the project for production:
```
npm run build
```

## Technologies Used

- React
- TypeScript
- Vite
- React Router DOM
